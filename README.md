# ULM Defensive Intelligence — Mississippi State v28

Down & Distance is now standardized across the app.

First-down buckets:
- P & 10
- 1 & 10
- 1 & 15+
- 1 & 5

2nd, 3rd and 4th down distance buckets:
- 1-2
- 3
- 4-6
- 7-9
- 10-12
- 13+

Updated:
- Situations now displays D&D only in this taxonomy.
- Run Game uses one standardized Down & Distance selector instead of the old Down + 1-3 / 4-7 / 8+ controls.
- Passing Heat Maps includes the same D&D selector.
- Coverage Response includes the same D&D selector.
- Rush Count includes the same D&D selector.
- The selected D&D carries across these scouting views so staff is always looking at the same situational definition.

First-down normalization:
- distance <= 5 -> 1 & 5
- distance >= 15 -> 1 & 15+
- all other first-down distances -> 1 & 10
